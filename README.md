# Recuperación de Información — cuadernos académicos

Este repositorio conserva prácticas y ejercicios del curso. Contiene ocho notebooks y material de datos. Los notebooks se verificaron como archivos JSON válidos, pero sus celdas no se ejecutaron en esta revisión.

## Proyecto documentado

El buscador independiente, sus dependencias, instrucciones y demostración visual están en [buscador-tfidf-bm25](https://github.com/TAnthonyR/buscador-tfidf-bm25).

![Demostración nueva de TF-IDF y BM25](https://raw.githubusercontent.com/TAnthonyR/buscador-tfidf-bm25/main/preview-busqueda.png)

## Organización

- `notebooks/`: prácticas originales del curso, agrupadas por tema.
- `ExamenIIB/`: ejercicios del segundo bimestre.
- `notebooks/data/13langchain/podcastdata_dataset.csv`: conjunto de datos existente, de aproximadamente 38 MB.

Para explorar los notebooks, instala Jupyter en un entorno virtual y abre `jupyter lab`. Cada cuaderno puede requerir bibliotecas, archivos o servicios adicionales; revisa sus primeras celdas antes de ejecutarlo. Conserva los créditos presentes en el material del curso.
